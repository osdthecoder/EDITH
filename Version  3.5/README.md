# EDITH

**by OBSYRA**

*Edit everything. Share nothing.*

EDITH is a free PDF and image toolkit that runs entirely in your browser.
Your files are processed on your own device and are not uploaded to any
server by EDITH.

> **Status:** early version. Some tools may have bugs. Please report problems
> by opening an issue.

## What it can do

**PDF:** merge, split, extract pages, delete pages, reorder or duplicate
pages, rotate, add page numbers, add a watermark, add text, add an image or
signature, highlight text, annotate, add headers and footers, compress,
reduce size, optimise, repair, compare, view metadata, PDF to images, PDF to
text, text to PDF, zip files, protect a PDF with a password, and remove a
password you already know, extract images from a PDF, and a beta Word to
PDF converter for simple documents.

**Images:** images to PDF, compress, resize, crop, rotate, convert between
JPG, PNG and WebP, and view image info.

**Files:** recent files and history (names and sizes only), with search,
sorting and clearing.

## What it cannot do (yet)

- Convert PowerPoint or Excel files to PDF, or Word files with complex layouts
  (Word to PDF is a beta for simple documents).
- Draw a signature by hand (you can add a signature as an image).

Compressing a PDF re-draws its pages as images, so the text in the
compressed file can no longer be selected.

## Privacy

No accounts, no analytics, no uploads of your files. See
[privacy.html](privacy.html) for details.

## Using it

Open the web address of this project's GitHub Pages site, or open
`index.html` in a modern browser (no other downloads are needed;
the PDF libraries are included). In Chrome on Android you can choose **Install app** to
add it to your home screen.
